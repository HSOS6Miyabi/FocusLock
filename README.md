# Game Focus Guard：Windows 全屏游戏防抢焦点工具

**适用系统**：Windows 10/11，桌面版游戏；需要 Windows 自带的 .NET Framework 4.x。无需安装 Python、Visual Studio，也无需默认以管理员身份启动。

## 运行方法

1. 解压完整压缩包到任意目录（例如桌面 `GameFocusGuard`）。
2. 先打开游戏，再双击 **`启动工具.cmd`**。首次启动会在本机用 Windows 自带的 C# 编译器生成 `GameFocusGuard.exe`；之后也可直接运行生成的 `.exe`。
3. 在下拉列表选中游戏进程（例如 `game.exe [PID ...]`），点击 **开始守护**。
4. 切回游戏。只有检测到游戏已在前台后，守卫才会真正开始工作。如果游戏在候选列表中没有明显名称，可参考 PID，或者寻找占满屏幕、显示“(无标题)”的窗口。
5. 检测到其他程序切到前台时，工具会记录其进程名、PID、窗口标题，并尝试恢复游戏焦点（最多四次，避免死循环）。

**快捷键：** `Ctrl + Alt + F10` 暂停或继续守卫。主窗口最小化后会进入系统托盘；双击托盘图标可重新打开窗口，右键可暂停或退出。

**主动切出：** 通过 `Alt + Tab`、`Win + Tab`、`Ctrl + Esc` 主动离开游戏时，工具会尽量自动暂停恢复；回到游戏会自动继续。为了不安装全局键盘钩子，这里采用低频键位采样，**极快的按键组合可能漏检**。要稳定地切出，请提前使用暂停快捷键或托盘菜单。

## 三个选项

| 选项 | 作用 | 建议 |
| --- | --- | --- |
| 仅观察，不自动抢回焦点 | 找出到底是什么程序抢焦点；不对游戏施加操作 | 第一次使用时先开启它，跑几分钟 |
| 如果游戏最小化，尝试恢复窗口 | 调用 Windows 接口恢复最小化窗口 | 标准建议开启；极少数游戏会黑屏或闪烁 |
| 增强恢复 | 临时附加 Windows 输入线程队列，再尝试切回游戏 | 默认关闭；标准模式无效、游戏没有严格反作弊时再试 |

记录保存在：`%LOCALAPPDATA%\GameFocusGuard\focus-events.log`，主界面可点击“查看日志文件”。根据日志识别具体弹窗来源后，优先在对应程序里关闭抢前台弹窗或更新提示。

## 不能保证的情况

- **真正的独占全屏已被操作系统切出时，外部工具可能只能切回，不能避免瞬间黑屏**；部分游戏已经自行最小化或释放了独占显示模式。
- 系统 UAC 安全桌面、锁屏、Ctrl+Alt+Del、部分管理员权限窗口，以及某些游戏反作弊环境，不能也不应强制绕过。
- 程序不会向游戏进程注入代码、篡改内存、安装驱动、发送伪造键盘输入，也不会主动关闭弹窗程序。这些是刻意保留的安全边界。
- 增强模式会改变输入线程关联，虽然执行后立即解除，但仍可能被游戏或反作弊视为异常；**联网竞技游戏建议只用“仅观察”或“标准模式”**。
- 普通管理员权限差异、系统专用界面或某些游戏的图形 API 可能导致恢复失败。工具会在四次失败后停止本轮重试，不持续刷屏。
- 本包提供可审计的源代码，并在用户 Windows 电脑上首次编译；本开发环境不是 Windows，**尚未进行真实全屏独占游戏实测**。

## 如果你希望进一步提高成功率

1. Windows 11：**设置 → 系统 → 通知 → 自动开启“请勿打扰”**，勾选“玩游戏时”和“全屏模式时”。这可以处理通知横幅，但不能阻止所有应用自己的弹窗。
2. 打开工具的“仅观察”，复现一次被切出，从日志找到进程名；如果是显卡升级器、聊天软件、游戏平台更新器，优先关闭其自动弹窗。
3. 如标准恢复不成功，可在你确定不触犯游戏反作弊规则的前提下，测试增强恢复。
4. 如果仍无效，试用**无边框窗口模式**；这往往降低独占全屏切出后恢复显示模式的成本，但不等同于禁止程序抢焦点。

## 源码与隐私

核心源代码为 `GameFocusGuard.cs`；启动器为 `启动工具.cmd`。工具只读取前台窗口、进程名、PID 和窗口标题，并将事件写入**你自己电脑**的本地日志；不上传任何信息。退出工具后事件监控与快捷键注册都会释放。
